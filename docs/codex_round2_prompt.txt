=== AUFGABE 2: Provenance-Kennzeichnung (verbindlich aus DATA_MAPPING) ===
Erweitere das Analysis-Schema ADDITIV um zwei optionale Felder:
- "dataSource": "fmp" | "yahoo"  — welche Primärquelle aktiv war
- "provenance": dict[str, "reported"|"computed"|"estimated"|"unavailable"] — Schlüssel = Feldpfad (z.B. "profitability.wacc"), siehe DATA_MAPPING-Tabelle.
Regeln: direkt vom Provider = reported; von uns aus Rohdaten berechnet = computed; Schätzung/Annahme = estimated; null weil nicht lieferbar/berechenbar = unavailable. Felder ohne Eintrag gelten als reported. Beide Felder optional → bestehender Vertrag + Frontend-Mock bleiben gültig.
Jeder Provider füllt provenance für die Felder, die er berechnet/schätzt/nicht hat. Yahoo: ROIC/WACC/interestCoverage → unavailable; FCF (OpCF-CapEx) und ROE (NI/Equity) → computed wo nötig.

WICHTIG zu valueCreating: nur true/false setzen wenn BEIDE (ROIC und WACC letztes Jahr) vorhanden sind; wenn eines null → valueCreating = null (Schema entsprechend Optional machen) und provenance "valueCreating"=unavailable. (Bei Yahoo also null statt irreführend false.)
